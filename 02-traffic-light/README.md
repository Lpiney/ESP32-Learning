# 02 · 三色 LED：交通灯 & 流水灯

第一个自己接线的课。代码很短，重点是手上的活：面包板怎么用、LED 怎么插、为什么必须串电阻。

## 硬件

- ESP32-S3 开发板
- LED：红、绿、蓝 各 1 个
- 电阻：红 220Ω、绿 220Ω、蓝 100Ω（都用 1/4W 金属膜电阻）
- 面包板 + 杜邦线

## 电路原理

**LED 有极性**：长脚 = 正极，接 GPIO 那一侧；短脚 = 负极，接 GND。
灯体上有一个平边，平边对应短脚。

**每个 LED 必须串一个电阻。** LED 导通后内阻极小，直接接到 3.3V 会瞬间流过
上百 mA——烧掉 LED，或者烧掉芯片引脚。串上电阻后电流被限制在安全范围：

    电流 = (3.3V − LED 压降) / 电阻

| LED | 压降 | 电阻 | 实际电流 |
|---|---|---|---|
| 红 | 约 2.0V | 220Ω | 约 6mA |
| 绿（普绿） | 约 2.1V | 220Ω | 约 5mA |
| 蓝 | 约 3.0V | 100Ω | 约 3mA |

蓝色 LED 压降最高，3.3V 减完剩不了多少，所以要用更小的电阻才够亮。
芯片引脚的安全上限约 20mA，上面这些值都很安全。

## 接线

面包板规则：中间区域的孔是「一竖列 5 个孔互相连通」，两侧的长条是电源轨
（两条贯通全板，专门走正负极）。

| ESP32-S3 引脚 | 经过 | 接到 |
|---|---|---|
| GPIO4 | 220Ω 电阻 | 红灯长脚（短脚 → 负极轨） |
| GPIO5 | 220Ω 电阻 | 绿灯长脚（短脚 → 负极轨） |
| GPIO6 | 100Ω 电阻 | 蓝灯长脚（短脚 → 负极轨） |
| GND | 杜邦线 | 面包板负极轨 |

电阻串在 GPIO 和 LED 长脚之间即可（串在短脚和 GND 之间也完全一样，串联电路处处电流相等）。

步骤：

1. 开发板 GND → 面包板负极轨
2. 三个 LED 跨着面包板中缝插（两个脚分别插在中缝两侧）
3. 电阻一端插在 LED 长脚同一列，另一端用杜邦线连到 GPIO4 / GPIO5 / GPIO6
4. 三个 LED 短脚都连到负极轨
5. 通电线再检查一遍：LED 极性、电阻是否串进去了

## 在 VS Code + PlatformIO 里怎么跑

1. VS Code → File → Open Folder… → 选择这个 `02-traffic-light` 文件夹
2. 第一次打开时 PlatformIO 会在底部状态栏初始化项目（要一会儿）
3. 底部工具栏的按钮（从左到右）：
   - **对勾图标 = Build**：只编译，检查代码写错了没有，不碰板子
   - **右箭头 = Upload**：编译并烧录到板子（板子插在标着 UART 的 Type-C 口）
   - **插头图标 = Serial Monitor**：打开串口监视器，看程序打印（本课有一行开机输出）
4. 上传成功后板子自动重启，LED 开始按交通灯节奏跑

## 代码导读（src/main.cpp）

- `#include <Arduino.h>`：Arduino 核心函数（pinMode / digitalWrite / delay…）的声明。
  Arduino IDE 会自动加这一行，PlatformIO 不会——忘写就会报一堆
  `'digitalWrite' was not declared` 错误。本课第一次编译就踩了这个坑，
  记住这个报错长什么样，以后一眼就能认出
- `pinMode(4, OUTPUT)`：告诉芯片「这个引脚用来输出电平」
- `digitalWrite(4, HIGH)`：引脚输出 3.3V，LED 亮；`LOW` 输出 0V，灭
- `delay(3000)`：原地等 3000 毫秒。注意它是「阻塞」的——等待期间芯片什么都不做，
  后面做多任务时会学用 `millis()` 的不阻塞写法
- 文件顶部的 `MODE`：改成 1 看交通灯，改成 2 看流水灯，重新上传即可

## 实验（改代码看现象，这是自学的正确姿势）

1. 把红灯时间从 3 秒改成 5 秒
2. 让流水灯来回跑：在 `runningLight()` 里再加一个反向的 `for` 循环
3. 把 220Ω 换成 1kΩ，观察亮度变化——电阻大了，电流小了，灯变暗
4. 想一想：如果拿掉电阻直接接，电流是多大？（别真试，可能烧 LED 或芯片脚）
